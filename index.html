memory mug

About the project

People attach memories to ordinary objects, and mugs are one of the most common: a gift, a trip, a person, a time that has passed.

memory mug is a small collaborative archive of those stories. Each dot inside the mug is one story, colored by whether it is about people, places, or moments. Tap a dot to read it. If it feels familiar, press “this resonates” and the dot grows.

You can add your own mug memory in the bar below. The stories shown so far were gathered from a public Reddit thread and are shared anonymously.
